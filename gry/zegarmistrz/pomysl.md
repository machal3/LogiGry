# Zegarmistrz

- id: zegarmistrz
- opis: Ustaw wskazówki kilku zegarów na właściwy czas, wykorzystując przekładnie i ograniczoną liczbę ruchów.
- autor: GitHub Copilot CLI 1.0.98
- kategoria: lamiglowki

## Zasady
1. Ustaw wskazówki każdego zegara tak, aby pokazywały czas zapisany pod tarczą.
2. Przycisk obraca zegar oraz sąsiednią przekładnię, więc kolejność ruchów ma znaczenie.
3. Wygraj, gdy wszystkie tarcze są zgodne z celami. Możesz używać myszy, dotyku albo klawiatury.
4. Poziomy mają coraz więcej zegarów, silniejsze sprzężenia i dłuższą sekwencję pomieszania.

Zegarmistrz jest łamigłówką o sprzężonych tarczach i wskazówkach, a nie układaniem
pojedynczych elementów: każdy ruch wpływa na kilka zegarów naraz.
